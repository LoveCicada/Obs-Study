## 图中内容

| 阶段 | 节点 | 对应源码 |
| --- | --- | --- |
| 采集 | 视频采集源 / 音频采集源 | `obs_source_output_video`（obs-source.c:3632）、`obs_source_output_audio`（obs-source.c:4066） |
| 合成 | 视频合成（图形线程）/ 转换与回读 / 树形混音（音频线程） | obs-video.c:539/583/1094、obs-audio.c:548 |
| 缓冲分发 | 视频帧缓存（≤16帧）/ 音频分发（1024采样/块） | media-io/video-io.c:35/190、media-io/audio-io.c:205 |
| 编码 | 视频编码（CPU）/ GPU 直通编码（NVENC 零拷贝）/ 音频编码 | obs-encoder.c:1456、obs-video-gpu-encode.c:24 |
| 输出 | 直播推流（RTMP/SRT/WHIP）/ 本地录制（MP4/MKV/FLV） | plugins/obs-outputs/rtmp-stream.c:632/1540、obs-output.c:2222 |

图下方四张卡片分别说明：视频主路径（乒乓纹理/跳帧机制）、音频路径（推送缓冲+拉取混音）、GPU 零拷贝旁路、输出交织与可靠性。

## 阅读提示

- 粗亮色（emphasis）流线为视频主数据路径；普通流线为音频/旁路/录制分支；
- 预览窗口渲染（`render_displays`）与主路径同循环执行，未在图中单列节点，见"视频主路径"卡片；
- 输出阶段存在少量流线交叉（编码器到推流/录制的扇出），属正常拓扑；
- 图中时间参数（16 帧缓存、1024 采样、≈21.3ms）均取自源码常量，非实测值。
